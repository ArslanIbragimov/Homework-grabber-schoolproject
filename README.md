# Сбор школьной домашней работы.
Версия - 1.0.0
Описание - Получение информации об школьной домашней работы с электронного журнала elschool.ru в виде скриншота и последних сообщений с мессенджера Telegram, с филтровкой спама и неактуальной информации

Также нужно ввести данные в config.ini, чтобы программа могла нормально функционировать

[ПРИМЕР ЗАПОЛНЕНИЯ config.ini (Homework-grabber-schoolproject/Important/config.ini)]:

[TlAuth]
class_chat = 10Х //(соблюдать точное название, если у вас группа называется -=10А-+, то так и нужно писать, лучше всего копировать и вставить, также можно использовать ссылку на канал).

[elschool]
login = Surname_Name0 // логин он электронного журнала
password = 12345qwerty // пароль от электронного журнала
